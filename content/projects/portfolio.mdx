<Overview>

This site. I rebuilt my portfolio from a single HTML file into a Next.js app, so projects, experience and notes are data instead of copied markup, and kept the GSAP animations that made the original feel like mine.

</Overview>

## Highlights

- Content as data: every project, role and note lives in one place, with longer write-ups in MDX.
- GSAP throughout: smooth scrolling, a paper plane flying the hero line, a draggable infinite project slider and a pinned timeline year.
- A paper-plane cursor that switches colour with the background.
- Built to be usable by everyone: reduced-motion support, visible keyboard focus and a skip link.
